# 围护桩反分析工具 (PileBackAnalysis)

基于测斜仪位移数据反算围护桩内力的桌面应用程序。通过对位移曲线进行拟合和求导，计算弯矩、剪力和土压力分布。

## 功能特性

### 数据输入
- **手动输入**：在文本框中直接输入或粘贴深度-位移数据
- **文件导入**：支持从 CSV 和 Excel (.xlsx) 文件导入数据
- **灵活格式**：自动识别逗号、空格、Tab 等分隔符
- **默认数据**：留空时自动使用内置样例数据进行演示

### 拟合算法

| 算法 | 说明 | 适用场景 |
|------|------|----------|
| **多项式拟合** | 3-9 阶可调 | 数据点较少、趋势平滑 |
| **三次样条** | k=3 平滑样条 | 通用场景，平衡精度与平滑度 |
| **五次样条** | k=5 平滑样条 | 需要更高阶导数时（如土压力） |
| **论文样条** | 逐点误差控制（毛朝辉2006） | 严格控制每个测点偏差不超限 |

### 平滑参数控制
- **三次/五次样条**：使用测斜仪预估误差 σ (mm) 控制平滑度，平滑因子 `s = N × σ²`
- **论文样条**：使用误差限 δ (mm) 控制每个测点的最大偏差，保证 |y(xᵢ) - ȳᵢ| ≤ δ
- **自动选择**：基于 L-curve 法自动寻找最优 σ/δ
- **参数范围**：σ/δ 范围固定为 0 ~ 2.500 mm

### 边界条件设置
- **桩顶边界**：可设置桩顶深度和位移值，强制曲线通过该点且弯矩为零
- **桩底边界**：可设置桩底深度和位移值，强制曲线通过该点且弯矩为零
- **奇对称镜像法**：通过数据镜像增强实现边界约束，确保 y(x₀) = 指定值, y''(x₀) = 0

### 力学计算

根据梁的弯曲理论，通过位移函数的各阶导数计算内力：

| 物理量 | 公式 | 单位 |
|--------|------|------|
| 位移 | y(x) | mm |
| 弯矩 | M(x) = E·I·y''(x) | kN·m |
| 剪力 | Q(x) = E·I·y'''(x) | kN |
| 土压力 | p(x) = E·I·y''''(x) | kPa |

### 可视化
- **2×2 四图布局**：同时显示位移、弯矩、剪力、土压力曲线
- **交互式十字线**：鼠标移动时实时显示各图对应深度的数值
- **原始点悬浮提示**：鼠标悬停在数据点上显示原始值
- **岩土工程习惯**：Y 轴深度向下为正

### 统计信息
- **拟合质量**：R²（决定系数）、RMSE（均方根误差）
- **极值信息**：最大弯矩 Mmax、最大剪力 Qmax、最大土压力 pmax
- **函数表达式**：显示位移拟合函数和弯矩函数的解析式

### 单点查询
输入任意深度值，查询该点的位移、曲率、弯矩、剪力和土压力。

## 使用方法

### 启动程序
```bash
python main.py
```

### 基本流程

1. **输入数据**
   - 在左侧文本框输入深度(m)和位移(mm)数据，每行一组
   - 或点击「从文件中读取」按钮导入 CSV/Excel 文件
   - 留空则使用默认样例数据

2. **设置边界条件**（可选）
   - 勾选「设置桩顶」设置桩顶边界（深度和位移）
   - 勾选「设置桩底」设置桩底边界（深度和位移）
   - 启用边界条件可强制曲线在边界点处弯矩为零

3. **设置参数**
   - 输入弹性模量 E（MPa 或 kPa）
   - 选择截面类型（圆形/矩形）并输入尺寸

4. **选择算法**
   - 多项式：拖动滑块调整阶数（3-9）
   - 样条：拖动滑块调整 σ 值（0~2.5mm），或点击「自动」按钮

5. **执行计算**
   - 点击「开始计算」按钮
   - 查看右侧四张曲线图和底部统计信息

6. **单点查询**（可选）
   - 在查询框输入深度值，点击「查询」

1.00  -0.81
1.50  -1.06

2.50  -0.41

## 算法说明

### L-curve 法自动选择最优 σ

在 log(残差) vs log(粗糙度) 空间中找 L 曲线拐角，平衡拟合精度与导数光滑性：

1. 在搜索范围内生成 50 个候选 σ 值（对数尺度）
2. 对每个 σ 值：
   - 拟合样条曲线 f(x)
   - 计算残差 ρ = Σ(yᵢ − f(xᵢ))²
   - 计算粗糙度 η = ∫f''(x)²dx（与弯矩平滑度直接相关）
3. 在 log(ρ)−log(η) 空间用 Menger 曲率找 L 曲线拐角
4. 拐角对应的 σ 即为最优值

### σ 搜索范围

σ 值范围固定为 0.001 ~ 2.500 mm，不再根据数据点数动态调整。

## 注意事项

- **土压力曲线**：由四阶导数计算，数值可能不稳定，仅供参考
- **五次样条**：需要至少 6 个数据点
- **论文样条**：需要至少 4 个数据点
- **自动选择**：L-curve 法仅需 50 次拟合，速度快
- **边界条件**：仅对样条拟合有效，多项式拟合不支持边界条件
- **左侧面板**：内容较多时支持滚动查看
