# PileBackAnalysis - 围护桩反分析工具

基于 Python + PyQt6 开发的桌面应用程序，用于围护桩的位移-弯矩反分析计算。

## 📋 功能特性

### 🎯 核心功能
- **数据输入**：支持 Excel/文本直接粘贴，自动解析深度(m)和位移(mm)数据
- **智能解析**：自动忽略表头和非数字行，支持多种分隔符（逗号、空格、Tab）
- **多项式拟合**：最小二乘法拟合，阶数范围 3~9（默认 5 阶）
- **弯矩计算**：基于材料力学公式 `M = E × I × y''` 计算弯矩分布
- **统计评估**：显示决定系数 R² 和均方根误差 RMSE

### 🔍 分析功能
- **可视化绘图**：双图显示位移对比和弯矩分布
- **任意查询**：输入任意深度，实时查询该点的位移、曲率和弯矩
- **实时统计**：显示拟合质量指标和最大弯矩值

### 🎨 用户界面
- **科技风格**：深色主题 + 霓虹色点缀的现代化界面
- **响应式布局**：左侧控制面板，右侧绘图显示区域
- **直观操作**：拖拽滑块调节参数，一键计算和查询

## 🚀 快速开始

### 环境要求
- Python 3.10+
- 已安装依赖包（见 `requirements.txt`）

### 运行程序
```bash
# 激活虚拟环境
conda activate pile_tool

# 启动应用程序
python main.py
```

### 使用步骤
1. **输入数据**：在左侧文本框粘贴深度和位移数据（格式：深度[TAB]位移）
2. **设置参数**：
   - 输入弹性模量 E 和单位（MPa/kPa）
   - 选择截面类型并输入尺寸（圆形：直径 D；矩形：宽度 b × 高度 h）
3. **调节拟合**：拖拽阶数滑块（3~9，默认 5）
4. **开始计算**：点击"开始计算"按钮
5. **查看结果**：
   - 右侧显示位移拟合曲线和弯矩分布图
   - 底部显示 R²、RMSE 和最大弯矩
6. **深度查询**：输入任意深度，点击查询查看详细结果

### 示例数据格式
```
0	0
2	-5
4	-18
6	-32
8	-50
```

## 📦 打包发布

生成单文件可执行程序（无需安装Python环境）：

```bash
pyinstaller --noconsole --onefile --name PileBackAnalysis main.py
```

打包后的 `PileBackAnalysis.exe` 可在任何 Windows 计算机上直接运行。

### 核心算法

1. **数据预处理**：将位移从毫米转换为米，进行数值计算
2. **多项式拟合**：使用 NumPy 的 `polyfit` 进行最小二乘拟合
3. **曲率计算**：对拟合多项式求二阶导数得到曲率分布
4. **弯矩计算**：应用公式 `M = E × I × y''` 计算弯矩
5. **统计评估**：计算 R² 和 RMSE 评估拟合质量

### 技术栈
- **GUI框架**：PyQt6 - 现代化桌面应用开发
- **数值计算**：NumPy - 高性能数组运算和多项式处理
- **数据处理**：Pandas - 数据导入导出支持
- **科学绘图**：Matplotlib - 专业级数据可视化
- **打包工具**：PyInstaller - Python 程序打包为可执行文件

## 💡 使用提示

1. **数据格式**：确保第一列是深度(m)，第二列是位移(mm)
2. **阶数选择**：一般 3~7 阶即可，过高可能过拟合
3. **单位注意**：深度为米，位移为毫米，弹性模量可选 MPa 或 kPa
4. **截面参数**：输入实际尺寸，程序会自动转换为米进行计算
5. **查询功能**：可在拟合完成后查询任意深度的计算结果

## 🐛 常见问题

- **拟合失败**：检查数据格式，至少需要 2 个有效数据点
- **显示异常**：确保输入的数值都在合理范围内
- **打包问题**：确认虚拟环境激活且所有依赖已安装
